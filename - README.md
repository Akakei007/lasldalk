
# Практическая работа №1.2 — Связи таблиц

## Предметная область

Приложение для хранения авторов и книг.

## Модели

- Author — автор: имя и страна.
- Book — книга: название, год издания и жанр.

## Тип связи

Один-ко-многим (1:N). Один автор может иметь несколько книг.

Связь реализована с помощью hasMany и belongsTo.
Внешний ключ authorId находится в таблице Book.

## Технологии

- Node.js
- Sequelize
- SQLite

## Запуск

Установить зависимости командой npm install.
Запустить приложение командой node index.js.

## Реализованные возможности

- Проверка подключения к базе данных.
- Создание связанных записей.
- Использование методов createBook и getBooks.
- Получение данных через include.
- Вывод результата в консоль.
